FAQ

How is my website hosted and kept safe long term?

Hosting and support with us is available from $50 per month. We can handle the domain setup, updates, backups, and technical maintenance so the site stays looked after without you needing to manage the fiddly parts. There are no minimum terms.

Can I still edit the site myself?

Yes. Quality Foundational includes a custom WordPress login and editable pages, so text and images are easy to update yourself.

Will there be hidden fees?

No hidden fees. This package is $1,750 and includes the five-page custom website, workable mockup, custom theme, custom contact or enquiry forms, custom WordPress login, editable pages, and two rounds of revisions. If you need extra functionality beyond that scope, we'll quote it clearly first.

Can I expand the site later if needed?

Yes. We build this on a custom WordPress theme, so when you are ready to add more pages or functionality later, the site can grow without needing to be rebuilt from scratch.
